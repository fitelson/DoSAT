# Retired UI references

These entry files preserve the earlier causal model finder, graphical rule checker,
classical baseline and landing page for code provenance and regression tests.
They are local development references, not production entries. Only root
index.html is built and published as DoSAT 1.0. The old public URLs redirect to
https://fitelson.org/DoSAT/.

The associated parser, solver, semantics documents and review records remain
unchanged. To inspect a reference locally use /reference-ui/<name>.html on the
strict development port. Do not upload this directory.
